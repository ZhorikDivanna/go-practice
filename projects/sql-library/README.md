# SQL Library

Учебная практика работы с PostgreSQL из Go на примере библиотеки книг.

## Возможности

- Создание таблицы книг.
- Добавление, получение, изменение и удаление записей.
- Постраничное чтение через LIMIT и OFFSET.
- Параметризованные SQL-запросы через pgx.

При запуске программа создаёт таблицу, если её нет, добавляет
демонстрационные записи в пустую таблицу и выводит книги
страницами по четыре.

## Стек

Go, PostgreSQL, pgx, Makefile.

## Запуск

Нужны Go, Make и работающая PostgreSQL.

1. Перейти в папку проекта.
2. Скопировать `.env.example` в `.env`.
3. Указать в `DATABASE_URL` подключение к существующей базе.
4. Выполнить `make run`.

Изменение и удаление представлены отдельными функциями;
при обычном запуске они не выполняются.
