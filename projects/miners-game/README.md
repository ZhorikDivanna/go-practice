# Miners Game API

Учебная симуляция шахты с HTTP API на Go. Игрок копит уголь, нанимает шахтёров и покупает оборудование. Шахтёры добывают уголь в отдельных горутинах и передают результаты через каналы.

Игровая логика находится в пакете `game`, а маршруты и обработчики — в `http`. Общий баланс и состояние игры защищены `sync.RWMutex`. При завершении игры `context` подаёт сигнал остановки шахтёрам. Состояние хранится в памяти.

## Запуск

Из папки проекта запусти `go run .`. Требуется Go 1.26.2 или новее. API слушает порт `9090`.

```bash
curl -i http://localhost:9090/status
curl -i http://localhost:9090/miners/prices
```

Баланс начинает расти после запуска. Когда накопится хотя бы 5 единиц угля, можно нанять первого шахтёра:

```bash
curl -i -X POST http://localhost:9090/miners \
  -H 'Content-Type: application/json' \
  -d '{"miner_type":"small"}'
```

| Метод и путь | Назначение |
|---|---|
| `GET /status` | Баланс, число активных шахтёров и купленное оборудование |
| `GET /miners/prices` | Стоимость найма по классам |
| `GET /miners/active` | Активные шахтёры. Можно указать `?class=small` |
| `POST /miners` | Найм. Поле `miner_type` принимает `small`, `normal` или `strong` |
| `GET /equipment/prices` | Оборудование, его стоимость и статус покупки |
| `POST /equipment` | Покупка по полю `name`: `pickaxe`, `ventilation` или `trolley` |
| `POST /finish` | После покупки всего оборудования возвращает итоги игры и останавливает сервер |
